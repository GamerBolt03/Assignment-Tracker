Gmail API Setup Guide

Step 1

Create a Google Cloud Project

Go to Google Cloud Console and create a new project. Name it anything (e.g. "Assignment Tracker").

Step 2

Enable the Gmail API

In your project, go to APIs & Services → Library, search for "Gmail API", click it, and click Enable.

Step 3

Configure OAuth Consent Screen

  • Go to APIs & Services → OAuth consent screen
  • Choose External (anyone can test), click Create
  • App name: "Assignment Tracker", enter your email, click Save
  • Skip scopes, skip test users (or add your email if asked)
  • Click Back to Dashboard
Step 4

Create OAuth Credentials

  • Go to APIs & Services → Credentials
  • Click + Create Credentials → OAuth client ID
  • Application type: Desktop app
  • Name: "Assignment Tracker"
  • Click Create
Step 5

Download & Upload client_secret.json

Click Download JSON on the credential you just created.
